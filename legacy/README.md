# legacy

Earlier generations of fikopar, kept as reference and as input for the COBOL importer. Not built by CI.

| Folder | Years | Stack |
|---|---|---|
| [cobol](cobol/) | 2010– | RM/COBOL, indexed files, PHP bridge to MySQL |
| [java-swing](java-swing/) | ~2015– | Java, Swing, Hibernate 4, JasperReports, MySQL |
| [jhipster-v2](jhipster-v2/) | 2023– | JHipster 7.9 (Spring Boot 2, React), PostgreSQL |

Data files, third-party jars/sources and screenshots are left out. Hardcoded credentials were replaced with environment placeholders.
