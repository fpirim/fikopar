# Screens → API

Operation IDs from [`api/openapi.yaml`](../api/openapi.yaml). All data paths are under `/api/orgs/{orgId}`.
The top-bar depot switch sets `depotId` on every call that takes it. Grids use the AG Grid Community
infinite model; Excel comes from the server (`Accept: …spreadsheetml.sheet`), CSV from the client.

| Screen | Operations | Notes |
|---|---|---|
| Login | `login`, `loginDemo`, `getHealth` | Build hash from `getHealth.version`. EN/TR is client state. |
| Sidebar, top bar | `getMe`, `listDepots`, `globalSearch` | Company switch lists `getMe.organizations`. Search groups accounts, parts, document numbers. |
| Dashboard | `getDashboard`, `gridDocuments`, `listStockLevels` | One call for the four tiles, latest activity, due this week, below minimum / negative (top 10, negative first, `belowMinCount` / `negativeCount`), ledger check. "Show all" = `listStockLevels` `only=BELOW_MIN_OR_NEGATIVE`. Latest documents = `gridDocuments` `statuses` POSTED + CANCELLED, sort `postedAt` desc, rows 0–10, top-bar depot; a row opens Invoice. |
| Balances | `gridBalances`, `printStatements`, `printReminderLetters` | As-of date, type segment and column filters (city, balance, overdue, last move) in one request; pinned row = `totals`, "6 of 412" = `totalCount` / `unfilteredCount`. |
| Statement | `getAccountStatement`, `getSicilSummary`, `getSicil`, `updateSicil` | Brought-forward row per depot, depot totals, Excel/PDF via Accept. Credit panel from the summary. A line with `documentId` (document entry or its reversal) links to Invoice. |
| 05 Invoice | `createDocument`, `updateDocument`, `deleteDocument`, `getDocument`, `postDocument`, `cancelDocument`, `searchCatalog`, `resolvePartCodes`, `getSicilSummary`, `gridSicil`, `gridDocuments`, `listNumberSeries`, `listMembers` | 11 types, return waybills included. Header: type, depot, date, ship date, due (default from the card's term), account, salesperson (`listMembers`, default from the card), waybill ref. (`waybillDocumentId`: picker = `gridDocuments` posted waybills of the matching type, card and depot; empty lines copy the waybill) or original (`linkedDocumentId` for returns and FF; lines from `getDocument` with qty − `returnedQty` as the cap). FF: direction Increase / Decrease (`priceDirection`, required); its grid is amount only (original line optional, description, amount, VAT); a Decrease over the invoice's remaining net is ERR_PRICE_DIFFERENCE_EXCEEDED on post. Grid: part (F2 popup), description, stock (`stockByDepot`, `reservedQty`), qty, price, D1 %, D2 %, VAT, net; pinned total row. F2 popup = `searchCatalog`: code / OEM / ALT / equivalent / name, stock of every depot, list price on the document date, equivalents, keyset paging. Side panel: gross, discount, subtotal, VAT per rate (`vatBreakdown`), total; "On post" from `effects` (account ±T, stock per depot, credit used after). Save draft = create / update (`If-Match`; reserves stock for 48 h, `reservation.expiresAt` shown); warnings STOCK_SHORT / CREDIT_LIMIT / PRICE_BELOW_LIST inline, never blocking. Post: 409 ERR_CREDIT_LIMIT_EXCEEDED shows limit, balance, total, excess; admins get "Post anyway" with a reason (`creditOverride`). Post and cancel return NEGATIVE_STOCK (toast). Cancel asks a reason; blocked by a bill (ERR_WAYBILL_BILLED) or returns (ERR_DOCUMENT_HAS_DEPENDENTS, `dependentDocumentIds` listed). Delete for drafts. PDF via Accept (DRAFT / CANCELLED marked). CSV import parsed in the client, codes via `resolvePartCodes`. Number shown on a draft is `nextValue`, allocated on post. |
| Documents (new) | `gridDocuments`, `deleteDocument` | List of all trade documents. Filters: type (multi), status, account (`sicilId`), depot (top bar), date range, number; floating column filters (`DocumentColId`); sort; pinned totals (net, VAT, total; cancelled rows left out); Excel from the server, CSV in the client. Row opens Invoice; "New" picks the type. Draft rows show no number. |
| Receipt | `createReceipt`, `getReceipt`, `voidReceipt`, `gridReceipts`, `getSicilSummary`, `listAccounts`, `listNumberSeries` | Methods cash / bank / cheque / note; cheque and note register the instrument in the same call. "Post & print" = create, then PDF. |
| Cheques & notes | `gridInstruments`, `getInstrumentSummary`, `getInstrument`, `listInstrumentEvents`, `operateInstrument`, `createInstrument` | Tabs and counts from the summary. Collect takes an amount (partial). "Returned by bank" = `BOUNCE`. History carries receipt numbers. |
| Cash book | `getCashBook`, `createCashVoucher`, `voidCashVoucher`, `createCashCount`, `listCashCounts` | Opening / in / out / closing in the response. Across a carried 1 January the OPENING line has `resetsBalance` and the running balance restarts there. Expense = GDR voucher, bank deposit = VRM voucher. |
| Parts & stock | `gridParts`, `createPart`, `getPart`, `updatePart`, `lookupPartByCode`, `getPartStock`, `setPartDepotSettings`, `getPartPriceHistory`, `setPartPrice`, `gridStockMovements`, `transferStock`, `getStockTransfer`, `listCatalogs` | Grid: floating filters per `PartColId`, sort, infinite paging, Excel (server) / CSV (client); depot switch scopes the stock columns, All depots adds one on-hand column per depot (`stockByDepot`); `stock` = In stock / Below min / Negative. Card: codes (OEM, ALT, equivalents), per-depot on hand, reserved, available, min, max, shelf (`If-Match` per depot row, `"0"` creates). Price history with future prices; new price with a date. Movements with running on-hand (part + date sort) and Excel; document rows show type label, number and account and open Invoice (`documentId`), reversals marked. Transfer returns `warnings`. |
| Catalogs & price import | `listCatalogs`, `createCatalog`, `updateCatalog`, `listPrices`, `setPrices`, `listPriceImports`, `createPriceImport`, `getPriceImport`, `updatePriceImport`, `gridPriceImportRows`, `applyPriceImport`, `discardPriceImport`, `listPriceImportPresets` | Upload CSV / XLSX / LISAKT, map columns (headers + sample when NEEDS_MAPPING), preview tabs New / Price / Attributes / Missing / Errors from `counts` and `change`, apply with `If-Match` (job version) and an `Idempotency-Key`; ERR_IMPORT_STALE → refresh with `updatePriceImport {}`. |
| Stock count | `listStockCounts`, `openStockCount`, `getStockCount`, `gridStockCountLines`, `setStockCountLine`, `getStockCountLine`, `addStockCountLine`, `finalizeStockCount`, `cancelStockCount` | One open session per depot; system quantity frozen at start (`startedAt`). Autosave per line with its own ETag; a 412 re-reads the line (`getStockCountLine`). Filters: shelf range, "Differences only" / "Not counted" / "Counted" = `only`. `movedSinceOpen` flags lines to recount. Count sheet PDF via Accept (`sheet` BLIND / WITH_SYSTEM). Post asks SKIP or ZERO for uncounted lines and returns `warnings`. Value = difference × last purchase cost; `costSource` LIST_PRICE / NONE lines are flagged. |
| Carry forward | `getCarryForward`, `setCarryForwardOverride`, `deleteCarryForwardOverride`, `postCarryForward`, `reopenCarryForward`, `listOpeningBalances` | Steps (`steps[]`), KPIs and READY / SKIP / EDITED rows in the preview; overrides send `If-Match` (preview version); preview PDF via Accept. |
| Journal entry | `getJournalEntry`, `getJournalEntryTrail`, `reverseJournalEntry`, `listJournalEntries` | Trail = audit, outbox, deliveries, stock. Owned entries answer 409 with the owner. |
| Migration | `listMigrationRuns`, `getMigrationRun`, `startMigrationRun`, `listQuarantine`, `getCopybookLayout` | Report PDF/XLSX via Accept. Demo allows dry runs only. |

PDFs: invoice (`getDocument`), receipt (`getReceipt`), statement (`getAccountStatement`, `printStatements`),
reminder letters, count sheet (`getStockCount`), cash book, carry-forward preview, migration report.

Carry forward step STOCK_COUNTS: blocked by an OPEN count dated in the closing year (`STOCK_COUNTS_POSTED`);
`YEAR_END_COUNTS` is a warning.

Not covered: the Order mockup (B2B order) stays outside the approved screens. Reservations come from draft sales
documents (v1.4); `reserved` in the stock responses is their sum.
